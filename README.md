# Lab_Java
Привіт це README файл для 9 лабораторних робіт з програмування на мові Java. 

Кожна з лабораторних робіт показує виконані задання по різним темам під час вивченя цієї мови програмування.

# Функціональність 

В цьому проекті знаходиться код до 9 лабораторних.
Кожна з них знаходиться в окремій папці.

# Установка та запуск
Для роботи з цім проектом треба встановити JDK 17 або вишче.
Після завантаження JDK в папці проекту відкриваємо папку src та в ній папку потрібної вам лабораторної роботи.
Після цього запускаемо файл з назвою Start і в вас запустится завдання.
